# 模板与提示词优化说明

本次优化围绕“找得到模板、填得清内容、看清将应用的提示词、保留已有工作”展开。

## 使用方式

**填入完整模板**：先填写必填内容，再检查预览。空的选填项不会成为空标题；必填项缺失时不能应用或复制成品提示词。生成模板可以选择标签语言；编辑模板默认保留原图语言，修改文字时使用明确的替换清单。

**只补充规范**：保留已有提示词，追加勾选的静态绘图约束。不会把整个模板任务、空字段或“未提供数据”之类的条件说明重复追加。重复规则会跳过。

**推荐参数**：默认不勾选。只有明确勾选后，才应用界面展示的尺寸、质量和格式；模型和生成数量保持原设置。

**示例与撤销**：示例只补空白项，保留已填内容。应用模板后可撤销提示词与本次改变的参数；后来另行修改的参数不会被撤回。继续改写提示词后收起旧撤销入口，避免覆盖新文字。

模板内部各字段的草稿在当前页面切换模板时保留。填入工作台后的提示词和参数沿用工作台的自动保存功能。

## 内容改进

- 将大段固定说明改成“目标、用户材料、画面要求、绘图约束”，保留必要信息，减少重复。
- 科研模板不把缺少的数据、误差线、显著性或预期结论补成真实结果；示例数据栏保持空白。
- 数据图明确用于版式设计，正式数值和比例应由数据绘图工具生成并核对。
- 编辑模板区分修改对象、位置与保留内容，不默认翻译原图文字。
- 海报模板使用给定文案，不自行补造活动日期、票价、评分或二维码。
- 界面模板明确输出静态视觉稿，不将图片描述为可运行页面。
- 常用约束可单独添加；不以提示词长短给出虚假的质量评分。

## 实现位置

- `src/lib/prompt-template-data.ts`：模板内容、字段、示例与约束。
- `src/lib/preset-prompts.ts`：稳定 ID、分类、模式过滤与搜索。
- `src/lib/prompt-tools.ts`：组装、校验、去重、应用及撤销逻辑。
- `src/components/prompt-template-dialog.tsx`：选择、填写与预览界面。
- `src/components/prompt-composer.tsx`：工作台入口、快捷约束、复制与撤销。
- 历史记录新增模板 ID，保存真实分类，并展示模板来源。
